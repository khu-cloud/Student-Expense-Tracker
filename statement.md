# Project Statement

## Problem Statement
Students often record daily spending informally, making it difficult to track total expenses, compare category-wise spending, and identify when a category exceeds a planned budget.

## Scope
The system records expenses, supports CRUD operations, searches expenses, stores category budgets, calculates spending summaries, checks budget status, and exports records to CSV.

## Target Users
Students who want a simple local tool for managing personal daily expenses.

## High-Level Features
- Add, view, update and delete expenses
- Search by category or keyword
- Category-wise spending reports
- Category budget setting and budget status
- JSON-based persistent storage
- CSV export
- Input validation and error handling
